# AETHER CLI

CLI application for the AETHER project.

> Run these with Python 3.12 or 3.13, other versions are not supported.

```bash
# Install the wheel bundle
python ./install.py
# run the mcp server
python entrypoint.py --idb <path-to-your-idb> --ida-dir <path-to-your-ida-installation>
```

Read more in `apps/docs` (follow the setup guide).

To uninstall,

```bash
python ./uninstall.py
```
