# MCP Client

It's just a typical `fastmcp` `Client` object with `list_tools` and `call_tool`
implemented.

The only difference is that a normal `fastmcp` `Client` needs to use an
`async with` block. However, since creating a new MCP client for every call is
inefficient — including for other features outside of the chatbot — we use
`__aenter__()` and `__aexit__()`.

These just mean that instead of `async with`, we manually enter and exit the
client.

Right now there is a `CallToolTask` to allow synchronous calls to MCP tools.
