# Component Lifecycle

This page documents the lifecycle of `StyledComponent` and how plugins are installed, used, and cleaned up. 
## Lifecycle Sequence

When a `StyledComponent` is constructed, these steps run in order:

1. `setup()`
   - Use this for early, non-UI state (load data, set flags, build model objects).
2. `init_ui()`
   - Create widgets, layouts, and child controls. Avoid calling `setStyleSheet()` here.
3. `install_plugins()`
   - Plugins are installed in priority order (higher first). Each plugin's `install()` runs.
4. `plugins_ready()`
   - Last chance to wire plugin interactions or cross-component behaviors.
5. Theme bootstrapping (from `ThemePlugin.install()`)
   - `_apply_styles()` runs once and then `on_theme_change()` runs once for initial paint.

When the theme changes later, the theme plugin runs:

1. `_apply_styles()`
2. `on_theme_change()`

When a widget closes:

1. `teardown()` runs for component cleanup.
2. Plugins uninstall in reverse order of installation.

## Example: Basic Lifecycle Hooks

```python
from PySide6.QtWidgets import QLabel

from aether_gui.utils.ui import StyledComponent


class StatusPanel(StyledComponent):
	def setup(self) -> None:
		self._status_text = "Loading"

	def init_ui(self) -> None:
		self._label = QLabel(self._status_text, self)

	def plugins_ready(self) -> None:
		# All plugins are installed at this point.
		self._label.setText("Ready")

	def on_theme_change(self, *, theme, colors) -> None:
		# Imperative updates that QSS cannot express.
		self._label.setText(f"Theme: {theme}")
```

Behavior: the label starts as "Loading", becomes "Ready" after plugins install, and updates its text on every theme change.

## Example: Plugin Install and Uninstall

```python
from PySide6.QtWidgets import QLabel, QWidget

from aether_gui.utils.ui.plugins import AbstractComponentPlugin


class BadgePlugin(AbstractComponentPlugin):
	@property
	def name(self) -> str:
		return "badge"

	def install(self, widget: QWidget) -> None:
		widget._badge = QLabel("Ready", widget)
		widget._badge.move(8, 8)

	def uninstall(self, widget: QWidget) -> None:
		badge = getattr(widget, "_badge", None)
		if badge is not None:
			badge.deleteLater()
			delattr(widget, "_badge")
```

Behavior: a "Ready" badge appears when the plugin installs and is cleaned up when the widget closes.

## Example: Template and Theme Updates

```python
from pathlib import Path
from PySide6.QtWidgets import QWidget

from aether_gui.utils.ui import StyledComponent


class InfoCard(StyledComponent):
	def init_ui(self) -> None:
		self._view = QWidget(self)

	def style_file(self) -> Path:
		return Path(__file__).with_name("info_card.qss.jinja")

	def template_file(self) -> Path:
		return Path(__file__).with_name("info_card.html.jinja")

	def on_theme_change(self, *, theme, colors) -> None:
		# Trigger any non-QSS updates here.
		_ = theme
		_ = colors
```

Behavior: QSS is re-rendered whenever the theme changes, and `on_theme_change()` runs after each style pass for any imperative updates.
