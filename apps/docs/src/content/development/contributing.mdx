# Contributing

Requires:
- `python 3.12 or 3.13`
- `ida >= 9.2`
- `mypy` IDE extension
- [`bun`](https://bun.com) for documentation

## IDE setup

1. Set your language server's option `Extra Paths` to `C:\Program Files\IDA Professional 9.x\python` (replace as needed).
2. Run `uv sync --all-packages` (`--allow-insecure-host <host>` if any ssl error).
3. Install the docs packages — see the [docs README](https://github.com/csitgovsg-acube/AETHER-next/blob/master/apps/docs/README.md) for the `bun` setup (including the Windows SSL workaround).
4. Add the pre-commit hooks `uv run pre-commit install`.

## Developer tooling

- Lint: `uv run ruff check`
- Format: `uv run ruff format`
- Unit tests: `uv run pytest apps/*/tests/unit packages/*/tests/unit`
- Integration tests: see [Integration Tests](/development/integration-tests)

## Config migration tool

To carry a legacy `AppData\Local\AETHER-IDA` config into the current AETHER Next
global config, run the one-shot tool:

```sh
python -m scripts.migrate_config.run
```

It converts the settings AETHER Next supports, backs up any existing config, and
writes the result, printing the `legacy_key -> destination` mapping and skipped
keys. See the [migration tool README](https://github.com/csitgovsg-acube/AETHER-next/blob/master/scripts/migrate_config/README.md) for the full OS path table and how to add a new mapping.
