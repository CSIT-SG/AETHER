## ChatbotPanel

The chatbot window. Connects `ChatInput` to `MessageArea` and starts the
`ChatOrchestrator`. Do not add backend logic here; it is a pure GUI component.

## MessageArea

Shows all messages: user input, LLM output, and tool output. Conversation history
is restored when the window is reopened.

The backend writes to it only through `ChatAreaProtocol`:

- `add_new_message_column`: start a new message
- `add_paragraph_to_last_column`: add a paragraph to the last message
- `append_to_last_paragraph_of_last_column`: append streamed text to the last paragraph

<Callout type="warning">
Backend code must not use `MessageArea` directly. Call `ChatAreaProtocol` methods
on IDA's main thread only.
</Callout>

## MessageColumn

One message: a header (name and timestamp), one or more `MessageParagraph`s, and
a copy button.

## MessageParagraph

One block of rendered Markdown.

<Callout type="warning">
Streamed text re-renders the paragraph on every chunk. Test long conversations
when changing this component or adding widgets to a message.
</Callout>

## ChatInput

- Ctrl+Enter or the send button submits. Enter adds a newline.
- While a response is running, the send button becomes a stop button.

## ResponseStatus

Shows "AETHER is responding…" while a response is running.

## SearchBar

Ctrl+F in the message area. Enter for next match, Shift+Enter for previous, Esc
to close.

## ButtonComponent

Button used for the copy action.

## Message

The message data model. Its role is `USER` or `AETHER`. Tool calls and tool
output use `AETHER`.

See [Orchestration](/development/gui/chatbot/orchestration) for how responses run.
