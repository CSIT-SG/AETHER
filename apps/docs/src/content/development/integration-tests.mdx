# Integration Tests

Run integration tests with `uv run pytest apps/*/tests/integration packages/*/tests/integration`, 
or scope to a single package with `uv run pytest packages/my_package/tests/integration`.

Set configuration with environment variables. These will be detailed later for each package.

## About test-fixtures

We have a set of predefined fixtures that provide testing binaries to run tests against.
These fixtures are generated in the `packages/test-fixtures` under an `_autogenerated/` directory built from the `src/assets/` directory.

To generate these fixures, you must have [`dockerd`](https://www.docker.com/) installed. Run `scripts/build.py`. 
This script will download `gcc`, compile all binaries in `src/assets/` for linux and windows and output in your host `_autogenerated/` directory.

There is a `pytest` plugin in `plugin.py` that just exports the file path to your test binaries with 
`get_binary(name: str, platform: str = platform.system())`. To use this fixture in other packages, put this in the `pyproject.toml`:

```toml
[tool.uv.sources]
aether_test_fixtures = { workspace = true }
```

Now, you can just use it in your test arguments, 
eg. `basic_bin_path = get_binary('basic')` to get the path to the binary `/_autogenerated/<your platform>/basic`.


### Note on manual generation

If you have your own `gcc` installed (you should have the compiler for linux and windows), you can compile the binaries yourself.

## Testing RPC

You must set the `env` variable `IDADIR="C:\Program Files\IDA Professional 9.2"` 
(basically the directory where you installed the `ida.exe` binary). 
This is to initialize the python package `idapro` which depends on this variable to run ida headlessly.

In `conftest`, we launch a headless IDA instance with the fixture `headless_ida` as a subprocess.

Then, write your tests in a class and add the decorator `@pytest.mark.dependency(depends=["connection"], scope="session")`. 
This stops the test if the connection to the launched ida fails. You can then use the `headless_ida` fixture as the connection object 
to run your tests.

For example:
```python
@pytest.mark.dependency(depends=["connection"], scope="session")
class TestGetFunctionByName:
    def test_finds_main_by_name(self, ida_client: rpyc.Connection) -> None:
        result = ida_client.root.get_function_by_name(function_name="main")
        assert result is not None
        assert result["name"] == "main"
```
