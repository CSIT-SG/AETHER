# System Architecture

![System Architecture](/architecture.svg)

This is the high-level architecture of Aether. The main components are:

- **IDA Pro**
- **AETHER rpc**: Provides a low level interface to IDA Pro's API, exposing it as a JSON-RPC server.
- **AETHER backend**: Manages connections between the many IDA Pro instances and implements tool call logic, exposing a higher level API to the LLM. 
    Also manages chatbot memory and holds system prompts.
- **Agents**: A collection of subagents that spawn from aether_backend. 
- **AETHER gui**: A gui client.
- **AETHER cli**: A command line client.

We will go into detail about each component, from the bottom up.

## Components

### IDA Pro

Your standard IDA Pro instance. There is an rpc plugin to expose its API, and a GUI plugin to display stuff.

<Callout type="info">
In the future, we may support other reverse engineering tools (e.g. Ghidra).
</Callout>

### Aether RPC

We expose low level access to IDA Pro's API via an RPC server. We use [rpyc](https://rpyc.readthedocs.io/en/latest/) for this.

There is one RPC server per IDA Pro instance. On IDA startup, it will register itself with the MCP controller server.

The only responsibility of this server is to forward low level IDA calls to the Aether MCP server.

<Callout type="warning">
Do not directly expose ida api calls. Use a wrapper to expose specific functionalities.
</Callout>

### Aether MCP

The MCP server is the core of the system. It manages all the IDA Pro instances and implements the logic for calling tools and agents.

We implement agent specific logic here, eg. memory management, system prompts, tool call logic, etc.

Under the hood, tool calls are routed to the appropriate RPC server.


### LLM and Agents

For each task, we have a collection of agents that can be called. Each agent has a specific role and set of tools it can call.

### Clients

We have two clients: a GUI and a CLI. Both clients are able to spawn agents (which then in turn call the mcp server) and display the results.

#### Aether GUI

We request the mcp server to spawn an LLM agent for each call. We just act as the client that sends requests and displays responses.

#### Aether CLI

<Callout type="warning">
Not implemented.
</Callout>

Same as the GUI, but in a command line interface.

## Dependency policy

We may drop support for older versions of IDA if there are breaking changes. 
Users are recommended to upgrade IDA or pin to an older AETHER version.

We may also not support the latest python version if any dependencies are reliant on an old version.

Read the current [system requirements](/getting-started#system-requirements).
