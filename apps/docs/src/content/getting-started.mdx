# Getting Started


## System Requirements

- Operating System: Windows or Linux
- Python: `3.12` or `3.13`

<Callout type="warning">
  Python 3.14 is not supported by IDA Pro due to compatibility issues with `PySide6`.
</Callout>

- IDA Pro: Version `9.2` or later
- LLM API Key: An OpenRouter API Key is required by default.

<Callout type="info"> 
    While pre-configured for OpenRouter, Aether supports any OpenAI-compatible API. 
    You can customize the provider by editing the configuration file.
</Callout>

## Installation
1. Clone the repository:

### Powershell

##### Requires Administrator Powershell

1. Open powershell as administrator and change directory to `\AETHER-next\apps\gui\scripts\PS`.
2. Run `./install-prod.ps1` or `./install-dev.ps1` for developers and users respectively,

<Tabs items={['Production', 'Development']}>
    <Tabs.Tab>
        <p>
            install-prod.ps1 copies relevant files from the repo into the Ida plugins folder. Though not recommended, it is safe to delete the repo from your computer.
        </p>
        <p>
            `./install-prod.ps1`
        </p>
    </Tabs.Tab>
    <Tabs.Tab>
        <p>

### Bash

##### Requires sudo privileges

1. Open terminal with sudo privileges and navigate to `\AETHER-next\apps\gui\scripts\Bash`.
2. Run `./install-prod.sh` or `./install-dev.sh` for developers and users respectively,
3. Ensure to set the `--plugins-dir` flag
