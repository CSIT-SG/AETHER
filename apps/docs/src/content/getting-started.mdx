# Getting Started


## System Requirements

- Operating System: Windows or Linux
- Python: `3.12` or `3.13`

<Callout type="warning">
  Python 3.14 is not supported by IDA Pro due to compatibility issues with `PySide6`.
</Callout>

- IDA Pro: Version `9.2` or later
- LLM API Key: An OpenRouter API Key is required by default.

<Callout type="info"> 
    While pre-configured for OpenRouter, Aether supports any OpenAI-compatible API. 
    You can customize the provider by editing the configuration file.
</Callout>

## Graphical User Interface (GUI)

### Powershell

Open powershell as **administrator** and change directory to `\AETHER-next\apps\gui\scripts\PS`.

<Tabs items={['Production', 'Development']}>
    <Tabs.Tab>
            ```
            ./install-prod.ps1
            ```
            `install-prod.ps1` copies relevant files from the repo into the Ida plugins folder. Though not recommended, it is safe to delete the repo from your computer.
    </Tabs.Tab>
    <Tabs.Tab>
            ```
            ./install-dev.ps1
            ```
            `install-dev.ps1` creates a symbolic link to the repo in the Ida. **DO NOT** delete the repo.
    </Tabs.Tab>
</Tabs>

### Bash

Open terminal with **sudo** privileges and navigate to `/AETHER-next/apps/gui/scripts/Bash`.

<Tabs items={['Production', 'Development']}>
    <Tabs.Tab>
            ```
            ./install-prod.sh --plugins-dir /path/to/ida/plugins/dir
            ```
            `install-prod.ps1` copies relevant files from the repo into the Ida plugins folder. Though not recommended, it is safe to delete the repo from your computer.
    </Tabs.Tab>
    <Tabs.Tab>
            ```
            ./install-dev.sh --plugins-dir /path/to/ida/plugins/dir
            ```
            `install-dev.ps1` creates a symbolic link to the repo in the Ida. **DO NOT** delete the repo.
    </Tabs.Tab>
</Tabs>

<Callout type ="info">
    Ensure to set the `--plugins-dir` flag. Default installation directory is `/opt/ida-pro-9.X/plugins`.
</Callout>
