# Getting Started


## System Requirements

- Operating System: Windows or Linux
- Python: `3.12` or `3.13`

<Callout type="warning">
  Python 3.14 is not supported by IDA Pro due to compatibility issues with `PySide6`.
</Callout>

- IDA Pro: Version `9.2` or later
- LLM Gateway: You need a openai-compatible LLM gateway and api key to use Aether. The default is OpenRouter, but you can configure your own provider in the [configuration file](./configuration).


## Graphical User Interface (GUI)

This is located in `apps/gui`. It is a plugin for IDA Pro that provides an interface for interacting with LLMs.

The install script will install the required dependencies and copy the plugin entrypoint into the IDA plugins folder. 
You can specify a custom plugins folder with the `--plugin-path` argument, eg. `python ./scripts/install_dev.py --plugin-path /opt/ida-9.2`.

### Development

Clone the repo and run the dev script.

```bash
git clone https://github.com/csitgovsg-acube/AETHER-next
cd apps/gui && python ./scripts/install_dev.py
```

This will install the required dependencies for idapython and link the plugin entrypoint into the IDA plugins folder.

### Headless Command-Line Interface (CLI)

Download the release binaries. The files are laid out in the following structure: 

<FileTree>
  <FileTree.Folder name="aether_cli" defaultOpen>
    <FileTree.Folder name="wheels" />
    <FileTree.File name="requirements.txt" />
    <FileTree.File name="install_prod.py" />
    <FileTree.File name="entrypoint.py" />
    <FileTree.File name="README.md" />
  </FileTree.Folder>
</FileTree>

Run the prod script.

```bash
python install_prod.py
```

This will install the wheel bundles and copy the plugin entrypoint into the IDA plugins folder.

Afterwards, you can run `entrypoint.py` with your IDA database path and the install directory of **IDA**.

You can also pass in the host address to run the **CLI** on.

For example:

```bash
python entrypoint.py --idb C:/path/to/your/idb/example.exe.i64 --ida-dir "C:/Program Files/IDA Professional 9.2"
```

After running `entrypoint.py`, you will get this output:
```bash
[aether.AETHER CLI] INFO: Config file can be found at C:/Users/asher.cheng/AppData/Local/AETHER-next/_global/config.json
[aether.AETHER_CLI_MCP] INFO: MCP server started at 127.0.0.1:50150
```

You can then use these to configure your provider and connect to the MCP server.
