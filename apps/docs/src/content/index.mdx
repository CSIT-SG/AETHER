# AETHER Next

AETHER is an advanced IDA Pro plugin that integrates Large Language Models (LLMs) into your reverse engineering workflow. 
It automates time-consuming tasks like function annotation, variable renaming, structure creation and contextual analysis, 
allowing security analysts to focus on deeper malware analysis and threat assessment.

The plugin leverages the IDA Pro Model Context Protocol (MCP) to communicate with LLMs while efficiently managing context and tokens. 
It is specifically designed for malware analysis, vulnerability research, and binary reverse engineering.
