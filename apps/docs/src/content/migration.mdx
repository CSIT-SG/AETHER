# Migration to AETHER-next

### Migration instructions for upgrading frin AETHER-IDA to AETHER-next.

<Callout type="info">
  You can ignore this if you have not installed previous versions of AETHER.
</Callout>

Performed using `migrate_config.run` script

#### Steps to use script

1. Download appropriate release version for your environment.
2. Install AETHER-next using `install_prod.py`.
3. run migration script

```sh
python -m scripts.migrate_config.run
```

<Callout type="info">
  Take note of GUI/CLI, OS and Python version when deciding which release to
  download.
</Callout>

## Migration Script

#### What it does

1. Locates the legacy config file.
2. Maps and translates parameters from legacy config to AETHER-next equivalents via `MAPPING` dictionary.
   - uses `id_to_name` method to perform translation.
   - Changes empty strings to `null`.
3. Creates new `config.json` file at appdata folder.

| OS      | Legacy AETHER-IDA                       | AETHER Next destination                          |
| ------- | --------------------------------------- | ------------------------------------------------ |
| Windows | `%LOCALAPPDATA%\AETHER-IDA\config.json` | `%LOCALAPPDATA%\AETHER-next\_global\config.json` |
| Linux   | `~/.local/share/AETHER-IDA/config.json` | `~/.local/share/_global/config.json`             |
