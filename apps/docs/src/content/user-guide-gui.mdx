## How to use AETHER (GUI)

Once you have successfully installed the GUI plugin and set your API key, follow the steps below to start using AETHER.

1. Start the backend server
2. Start IDA Pro and open a binary
3. Press `tab` to open the `decompile view` in IDA Pro
4. Right click anywhere in the `decompile view` to open the context menu
5. Click on the `AETHER-next` dropdown to access the functions of AETHER.
   <Callout type="info">
     NOTE: AETHER is only accessible from the `decompile view`.
   </Callout>

### Annotator

The Annotator is a tool that enhances readability of decompiled code. It does this by adding comments, renaming variables and renaming functions.

The Annotator will analyse the decompile code starting at the **current function on screen** and add the annotations.

![Annotator](/annotate.png)

#### Usage:

1. Right click **anywhere** in the `decompile view` to open the context menu
2. Click on the `AETHER-next` dropdown
3. Click on `Annotate Function` to start the annotation process.
   <Callout>
     This will take a while and the LLM output can be seen in the IDA `Output`
     Window
   </Callout>

### Struct Manager

The Struct Manager is comprised of the `create` and `re-evaluate` functionalities. This aids the creation of structs in the reverse engineering process.

The Struct Manager will look at the **highlighted variable** in the decompile view and create a struct for it.
It takes into account the context in which the variable exists and that which it's function is called. Using this information, it will generate a struct that is most likely to be correct.

<Callout type="info">
  NOTE: you __MUST__ highlight a variable to use the struct create and
  re-evaluate functionalities.
</Callout>

![Struct Manager](/struct_manager.png)

#### Usage(create):

1. Highlight a variable in the `decompile view`
2. Right click to open the context menu
3. Click on the `AETHER-next` dropdown followed by the `struct manager` dropdown
4. Click on `Create Struct` to start the struct creation process.
   <Callout>
     This will take a while and the LLM output can be seen in the IDA `Output`
     Window
   </Callout>

#### Usage(re-evaluate):

1. Highlight a variable in the `decompile view`
2. Right click to open the context menu
3. click on the `AETHER-next` dropdown followed by the `Manage Struct` dropdown
4. Click on `Re-evaluate Struct` to start the struct re-evaluation process.
   <Callout>
     This will take a while and the LLM output can be seen in the IDA `Output`
     Window
   </Callout>

### Chatbot

The Chatbot is a tool that allows you to interact with the decompiled code in a conversational manner.
You can ask questions about the code, request explanations, or seek guidance on specific functions or variables.

The Chatbot also has access to the `annotator` and `struct manager` functionalities. This allows you to request for annotations or struct creation directly from the chatbot.

![chatbot](/chatbot.png)

#### Usage:

1. Right click **anywhere** in the `decompile view` to open the context menu
2. Click on the `AETHER-next` dropdown
3. Click on `Open AI Chatbot` to open the chatbot window.
4. type your prompt into the input box, press `enter` to create new lines and `ctrl + enter` to send the prompt to the chatbot.

![chatbot window](/chatbot_window.png)
